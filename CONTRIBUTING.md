# Contribuindo com o Tusab

O código do Tusab é **source-available** (ver [LICENSE](LICENSE)) — você
pode ler, auditar, rodar e modificar para uso próprio. Isso é deliberado:
é a prova de que o princípio local-first ("seus dados nunca saem da
máquina") é verificável, não só uma promessa de marketing.

## Sobre Pull Requests

**No momento, não estamos aceitando Pull Requests externos.** O Tusab é
mantido por uma única pessoa (Augusto Brasil). Aceitar contribuições
externas exigiria triagem, revisão de segurança e um processo de CI que
ainda não existem — isso pode mudar no futuro, mas não é o estado atual.

## Como ajudar mesmo assim

- **Bugs e sugestões**: abra uma [issue](https://github.com/criaugu/tusab/issues) — é lida e usada para priorizar o roadmap.
- **Dúvidas técnicas sobre a arquitetura**: a [documentação técnica](https://criaugu.github.io/tusab/) descreve a arquitetura, as decisões técnicas e onde fica cada parte do código.
- **Forks**: são bem-vindos nos termos do [LICENSE](LICENSE) — só não use o nome/marca "Tusab" (ver [TRADEMARK.md](TRADEMARK.md)).
