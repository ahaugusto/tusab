# Contribuindo com o Tusab

O código do Tusab é **source-available** (ver [LICENSE](LICENSE)) — você
pode ler, auditar, rodar e modificar para uso próprio. Isso é deliberado:
é a prova de que o princípio local-first ("seus dados nunca saem da
máquina") é verificável, não só uma promessa de marketing.

## Sobre Pull Requests

**No momento, não estamos aceitando Pull Requests externos.** O Tusab é
mantido por uma única pessoa (Augusto Brasil) com apoio de agentes de IA
(ver `CLAUDE.md`), com um processo de desenvolvimento e revisão pensado
pra esse formato específico. Aceitar contribuições externas exigiria
triagem, revisão de segurança e um processo de CI que ainda não existem
— isso pode mudar no futuro, mas não é o estado atual.

## Como ajudar mesmo assim

- **Bugs e sugestões**: abra uma [issue](https://github.com/ahaugusto/tusab/issues) — é lida e usada para priorizar o roadmap.
- **Dúvidas técnicas sobre a arquitetura**: o `CLAUDE.md` na raiz do repositório documenta a arquitetura em camadas, as decisões técnicas não óbvias e onde encontrar cada parte do código.
- **Forks**: são bem-vindos nos termos do [LICENSE](LICENSE) — só não use o nome/marca "Tusab" (ver [TRADEMARK.md](TRADEMARK.md)).
