Pull Requests externos não são aceitos no momento — ver [Contribuindo](/contribuindo).

## Marca "Tusab"

O nome **"Tusab"**, o logo e a identidade visual associada são marcas de **CriAugu — Augusto Alves Brasil (CNPJ 65.131.075/0001-57)**, com registro INPI pendente. Essas marcas **não estão cobertas pela licença de código** — a licença de código é automática e independe do registro de marca (Lei nº 9.610/1998); o registro no INPI protege o nome/logo separadamente.

### O que isso significa na prática

Você pode usar, copiar, modificar e distribuir o código deste repositório nos termos da licença. Você **não pode**:

- Usar o nome "Tusab" ou o logo num fork, distribuição modificada ou produto derivado de forma que sugira ser o projeto oficial ou endossado pela CriAugu
- Publicar um fork nos mesmos canais de distribuição (GitHub Releases, lojas de aplicativo) usando o nome "Tusab"

Se você distribuir uma versão modificada, dê um nome diferente ao fork e deixe claro que é um projeto derivado, não afiliado ao Tusab original.
