# Contribuindo

O código do Tusab é **source-available** sob a [Elastic License 2.0](https://github.com/criaugu/tusab/blob/main/LICENSE): qualquer pessoa pode ler, auditar, rodar e modificar para uso próprio. Isso também permite conferir no código o que esta documentação afirma sobre dados ficarem no computador.

## Pull Requests

**No momento, Pull Requests externos não são aceitos.** O projeto tem um único mantenedor, e aceitar contribuições externas exigiria triagem, revisão de segurança e um processo de integração contínua que ainda não existem.

## Como ajudar

- **Bugs e sugestões:** abra uma [issue no GitHub](https://github.com/criaugu/tusab/issues). Para bugs, informe o sistema, a ferramenta de IA usada, a versão do plugin (ferramenta `tusab_status` ou `tusab-mcp/package.json`) e os passos para reproduzir.
- **Dúvidas sobre o código:** comece por [Arquitetura técnica](/arquitetura/visao-geral) e [Desenvolvimento](/desenvolvimento/setup).
- **Forks:** permitidos nos termos da licença, sem usar o nome ou a marca "Tusab" (ver [Licença](/licenca)).
