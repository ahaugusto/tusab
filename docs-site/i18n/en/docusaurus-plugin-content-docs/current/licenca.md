# License

## Code — Elastic License 2.0

Tusab's source code is **source-available** under the [Elastic License 2.0](https://github.com/criaugu/tusab/blob/main/LICENSE): it can be read, audited, run and modified for your own use. The relevant restriction is **not offering Tusab as a hosted or managed service to third parties**.

The extension package declares `"license": "Elastic-2.0"` in `manifest.json` and carries the `LICENSE` and `TRADEMARK.md` files (copied from the root by `scripts/gerar-licencas.mjs`).

## Third-party libraries

| Where | File |

| Extension (plugin and screen bundled in the `.mcpb`) | `tusab-mcp/THIRD_PARTY_NOTICES.txt`, generated by `node scripts/gerar-licencas.mjs` with the full license text of each library |
| Repository | [`THIRD_PARTY_NOTICES.md`](https://github.com/criaugu/tusab/blob/main/THIRD_PARTY_NOTICES.md) at the root (direct dependencies of the extension and the screen) |
| Desktop app (discontinued) | [`THIRD_PARTY_NOTICES.md`](https://github.com/criaugu/tusab/blob/desktop-final/THIRD_PARTY_NOTICES.md) and [`THIRD_PARTY_NOTICES.txt`](https://github.com/criaugu/tusab/blob/desktop-final/THIRD_PARTY_NOTICES.txt) in the `desktop-final` tag |

The libraries bundled in the extension use permissive licenses (MIT, ISC, BSD, Apache-2.0, BlueOak).

## Trademark

The "Tusab" name and logo **are not covered by the code license**. A fork or modified version needs a different name and can't suggest it is the official project. Full terms in [`TRADEMARK.md`](https://github.com/criaugu/tusab/blob/main/TRADEMARK.md).

## Source content

Tusab's license covers the code, not the content the user stores in the base. Transcripts, documents and public source results follow the terms of each origin (for example, Stack Overflow and Wikipedia use CC BY-SA; Tusab keeps each item's link, and for Stack Overflow also the author and the license).
