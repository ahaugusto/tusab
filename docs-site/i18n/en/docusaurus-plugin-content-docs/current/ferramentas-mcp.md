# MCP tools

Tusab registers **15 tools** (defined in `tusab-mcp/src/servidor.js` and listed in `tusab-mcp/manifest.json`). Each tool's title appears in the conversation in the language of the Tusab screen (see [Languages](/funcionalidades/idiomas)); the names (`tusab_*`) and parameters don't change. Parameter names are in Portuguese, as in the code.

Every tool that returns content from the base tells the AI that **the returned text is data from the sources, not instructions**. The server instructions also ask the AI to cite every statement (title and, for videos, `▶ MM:SS` with a link), to say when the base doesn't give enough support, to add content only when the user asks, and to answer in the user's language.

## Querying (read-only)

| Tool | What it does | Parameters |
|---|---|---|
| `tusab_buscar` | Relevance search in the index (FTS5/BM25, accent-insensitive). Returns excerpts with title, author, minute (`▶ MM:SS`), project, `fonte_id` and a link with `&t=Ns` | `consulta` (required); `projeto` (without it, searches all); `limite` 1–20, default 8 |
| `tusab_listar_projetos` | Lists projects with the number of sources, videos and excerpts, and the coverage of each channel (extracted/mapped) | — |
| `tusab_ler_fonte` | Reads a source in order, to see the context around an excerpt | `fonte_id` (from `tusab_buscar`); `a_partir_do_minuto` (e.g. `12.5` = 12:30); `max_trechos` 1–60, default 20 |
| `tusab_ler_original` | Opens a document's original file when the text is not enough. An image comes back as an image (up to 3 MB, without metadata); a PDF comes back by pages | `fonte_id`; `paginas` (PDF only: `"3"` or `"2-4"`, at most 10 pages) |
| `tusab_fontes_publicas` | Lists the 70 public sources by area, with each one's `id` and whether it accepts a date filter | `area` (optional, e.g. `saude`, `direito`) |
| `tusab_novidades_semana` | Lists the files added to the project in the last 7 days | `projeto` |
| `tusab_revisao_hoje` | Lists the project's flashcards due today (spaced repetition) | `projeto` |
| `tusab_economia` | Summary of [token savings](/funcionalidades/economia-de-tokens): tokens sent × tokens of the full sources | — |
| `tusab_status` | Repository folder, plugin version, running extraction, queue and the engine's last 5 messages | — |

Details of `tusab_ler_original` (types, limits and metadata removal) are in [Originals and images](/funcionalidades/originais-e-imagens).

## Writing (change the base)

| Tool | What it does | Parameters |
|---|---|---|
| `tusab_adicionar_youtube` | Extracts the transcripts of a channel (`@name`), playlist or video on this computer and indexes them. Runs in the background; if an extraction is already running, it joins the queue | `url`; `projeto` (created if it doesn't exist); `max_videos` 1–5000 (without it, extracts everything) |
| `tusab_adicionar_arquivo` | Copies a `.txt`, `.md` or `.markdown` file from the computer into the project's texts | `caminho` (full path); `projeto`. 5 MB limit. PDF, Word, Excel and images go in through the screen |
| `tusab_buscar_fonte_publica` | Searches a topic in a public source and **saves** the results as project documents. Waits up to 4 minutes; beyond that, the search continues in the background | `fonte_id`; `consulta` (2–300 characters); `projeto` (up to 120, created if it doesn't exist); `max_resultados` 1–50, default 10; `data_inicio` and `data_fim` (`YYYY-MM-DD`) |
| `tusab_salvar_estudo` | Saves study material **generated by the AI**, for review in other conversations | `projeto` (existing); `tipo`: `flashcards` (1 to 30 `{pergunta, resposta}`, question up to 500 and answer up to 2,000 characters), `postits` (1 to 30 sentences of up to 400) or `resumo` (Markdown); optional `tema`, `titulo`, `fontes` |
| `tusab_registrar_revisao` | Records the grade (0 to 5) of a reviewed flashcard and returns the next date (SM-2 algorithm, the same as the desktop app) | `projeto`; `card_id`; `qualidade` 0–5 |
| `tusab_abrir_painel` | Starts the local screen and returns the link (with the session key) | `abrir_navegador` (default `true`; `false` only returns the link) |

Writing tools are marked `readOnlyHint: false`; `tusab_adicionar_youtube` and `tusab_buscar_fonte_publica` are also marked `openWorldHint: true`, because they access the internet (YouTube and the public source).

## Typical flow

1. `tusab_listar_projetos` to see what exists.
2. `tusab_buscar` with the question; the AI answers citing the excerpts.
3. `tusab_ler_fonte` when more context around an excerpt is needed, or `tusab_ler_original` when the extracted text is not enough (table, chart, scanned PDF).

For study: the AI generates flashcards from the excerpts, saves them with `tusab_salvar_estudo` and, in another conversation, uses `tusab_revisao_hoje` and `tusab_registrar_revisao` (see [Study and spaced repetition](/funcionalidades/estudo)).

## MCP prompts

Besides the tools, the server registers the prompts of the [Prompt Library](/biblioteca-de-prompts) and the `abrir_tusab` shortcut ("Open Tusab"), which appear in Claude Desktop's "+" menu.
