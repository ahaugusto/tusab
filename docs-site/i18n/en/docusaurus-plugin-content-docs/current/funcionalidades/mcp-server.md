# MCP Server

Tusab exposes your indexed knowledge base to any client compatible with the [Model Context Protocol](https://modelcontextprotocol.io) — Claude Code, Cursor, or any editor/agent that supports MCP.

In practice: you query your own sources (videos, documents, notes) without leaving the tool you're already working in.

## How to connect

1. Open the **Admin** tab in Tusab
2. Click **"Copy MCP config"**
3. Paste the config into your MCP client of choice (Claude Code, Cursor, etc.)

The corresponding backend endpoint is `GET /agent/mcp/config`.

## What's available to the MCP client

Any content indexed in the project — including YouTube transcripts, documents, texts, and the artifacts generated by [Study Mode](/funcionalidades/modo-estudo), since those also enter the BM25 index.
