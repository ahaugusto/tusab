# Study and spaced repetition

Flashcards, post-its, summaries, quizzes and mind maps are generated by **the user's AI**, from the base's excerpts and the [built-in prompts](/biblioteca-de-prompts). Tusab keeps what needs memory across conversations, since the AI doesn't remember from one conversation to the next: the flashcards and the spaced repetition state. Code: `tusab-mcp/src/nucleo/estudo.js`.

## Flow

1. The user picks a study prompt (for example, **Flashcards** or **Study summary**) in Claude's "+" menu or copies it from the Prompt Library.
2. The AI searches the base (`tusab_buscar`), generates the material citing the sources and saves it with `tusab_salvar_estudo`.
3. In another conversation, the **Review today** prompt makes the AI call `tusab_revisao_hoje`, show one question at a time, compare the user's answer with the card's, give a grade from 0 to 5 and record it with `tusab_registrar_revisao`, which returns the next date.
4. The saved material shows up in the **Materials** tab of the screen, by project (the list refreshes every 10 s and when the window gets focus back). Each item opens in a dialog: flashcards with card flip and spaced repetition grading, summary and document in Markdown (with tables), sticky notes. They can be renamed, deleted, copied and exported as PDF.

## What can be saved

| Type | Content accepted by `tusab_salvar_estudo` |
|---|---|
| `flashcards` | 1 to 30 items `{pergunta, resposta}`; question up to 500 characters, answer up to 2,000; repeated questions in the same batch are refused |
| `postits` | 1 to 30 sentences of up to 400 characters |
| `resumo` | Markdown text (up to 30,000 characters) |
| `documento` | Markdown text (up to 60,000 characters): anything that is not a summary, such as a quiz, mind map (`mermaid` block, shown as code), lesson plan, test, technical note, script. It is stored only as material; it does not change the files in `management/` |

Optional: `tema` (up to 200 characters), `titulo` (up to 150) and `fontes` (up to 50 titles). The project must exist. If the input is refused, nothing is written and the tool returns a message the AI can use to fix it and try again.

## Spaced repetition

- **SM-2** algorithm, with the same calculation (including rounding) as the desktop app.
- Each flashcard's ID is the first 12 hexadecimal characters of the SHA-1 of the question.
- Each card stores repetitions, interval in days, ease factor, last and next review.

## Weekly digest

The **Weekly digest** prompt asks the AI to see what was added to the project in the last 7 days (`tusab_novidades_semana`), read it with `tusab_buscar`/`tusab_ler_fonte` and write 3 to 5 bullet points with the source of each.

## Files

```
data/neural/{projeto}/management/
  flashcards.json             latest batch of flashcards
  postits.json                latest batch of post-its
  resumo_estudo.md            latest summary
  flashcards_progresso.json   spaced repetition state per card
data/neural/{projeto}/estudo/
  _manifest.json              list of artifacts (most recent first)
  estudo_{tipo}_{data}.txt    artifact text
  estudo_{tipo}_{data}.json   structured data
```

The format is the same as the [desktop app's Study Mode](/funcionalidades/modo-estudo): a project studied in one opens in the other.
