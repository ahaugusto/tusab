# Contributing

Tusab's code is **source-available** under the [Elastic License 2.0](https://github.com/criaugu/tusab/blob/main/LICENSE): anyone can read, audit, run and modify it for their own use. That also makes it possible to check in the code what this documentation states about data staying on the computer.

## Pull Requests

**External Pull Requests are not accepted at the moment.** The project has a single maintainer, and accepting external contributions would require triage, security review and a continuous integration process that don't exist yet.

## How to help

- **Bugs and suggestions:** open an [issue on GitHub](https://github.com/criaugu/tusab/issues). For bugs, include the system, the AI tool used, the plugin version (tool `tusab_status` or `tusab-mcp/package.json`) and the steps to reproduce.
- **Questions about the code:** start with [Technical architecture](/arquitetura/visao-geral) and [Development](/desenvolvimento/setup).
- **Forks:** allowed under the license terms, without using the "Tusab" name or brand (see [License](/licenca)).
